# Lab 13: Backend CI/CD

This repository groups the three API projects used in the lab:

- `spring-api/` — Spring Boot API (Maven)
- `express-api/` — Express API (Node.js)
- `laravel-api/` — Laravel API (PHP)
- `.github/workflows/` — GitHub Actions workflows

Local environment files, dependency directories, build output, and IDE files are excluded from version control. Copy each `.env.example` to `.env` and fill in local values before running a project.
